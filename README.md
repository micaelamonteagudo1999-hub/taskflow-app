 TaskFlow
TaskFlow es una aplicación móvil desarrollada con React Native y Expo, pensada para organizar y gestionar tareas de manera sencilla.

 Checkpoint 1: Estructura Base
En este primer checkpoint se creó la estructura inicial del proyecto y se preparó la aplicación para poder continuar con el desarrollo de las próximas etapas.
La aplicación cuenta con una pantalla inicial que muestra el nombre de TaskFlow y el mensaje correspondiente al checkpoint.
También se organizaron las carpetas principales del proyecto para mantener los archivos ordenados y facilitar el desarrollo futuro.

 Estructura del proyecto
- `src/components`: contiene los componentes que podrán reutilizarse en distintas partes de la aplicación.
- `src/screens`: destinada a las diferentes pantallas de la aplicación.
- `src/assets`: contiene imágenes y otros recursos que se puedan utilizar.
- `src/theme`: destinada a estilos y elementos generales de diseño.

 Tecnologías utilizadas
- React Native
- Expo
- JavaScript
